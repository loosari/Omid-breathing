# Omid Breathing v3

نسخه حرفه‌ای‌تر وب‌اپ تمرینات تنفسی امید.

## قابلیت‌های این نسخه

- انتخاب هدف تمرین
- تمرین‌های آماده و داده‌محور
- انتخاب مدت ۱، ۳، ۵ و ۱۰ دقیقه
- ساخت و ذخیره الگوی تنفس سفارشی توسط کاربر
- نگهداری الگوهای سفارشی در localStorage
- cue صوتی نرم و اختصاصی برای دم، مکث و بازدم
- صدای پایان تمرین
- صدای ambient اختیاری
- راهنمای صوتی فارسی
- ویبره مرحله‌ای
- کاهش حرکت
- طراحی مناسب موبایل و دسکتاپ
- safety messaging
- بدون کتابخانه خارجی

## ساخت تمرین سفارشی

کاربر می‌تواند زمان دم، مکث و بازدم را وارد کند، مدت جلسه را انتخاب کند، الگو را پیش‌نمایش ببیند و آن را ذخیره کند. الگوهای سفارشی با مرورگر کاربر ذخیره می‌شوند.

## صداها

فایل‌های صوتی در `assets/audio/` قرار دارند و برای جلوگیری از وابستگی به سرویس خارجی به‌صورت local ارائه می‌شوند.
